# How many type of Attackers?
## In Cyber Security, there are 8 common types of attackers:
### 🔐 Types of Cyber Security Attackers
1. Black Hat Hackers – Hackers who access systems illegally for malicious purposes.
2. White Hat Hackers – Ethical hackers who find security weaknesses with permission.
3. Grey Hat Hackers – Hackers who may access systems without permission but do not always have malicious intentions.
4. Script Kiddies – Beginners who use ready-made tools to attempt cyber attacks.
5. Hacktivists – Attackers motivated by political or social causes.
6. State-Sponsored Hackers – Hackers supported by governments for cyber espionage or other operations.
7. Insiders – Employees or trusted individuals who misuse their authorized access.
8. Cyber Terrorists – Attackers who use cyber activities to create fear or disrupt important services.
# Day 4
# What is Cyber Threats?
🔐 What are Cyber Threats?
Cyber threats are potential dangers or malicious activities that can damage computer systems, networks, applications, or steal sensitive information. These threats can lead to data loss, financial loss, privacy violations, and unauthorized access.
🛡️ Types of Cyber Threats
1. Malware: Malicious software designed to damage or disrupt computer systems.
2. Phishing: Fake emails or messages used to trick people into sharing personal information.
3. Ransomware: Malware that locks or encrypts data and demands payment.
4. Virus: A malicious program that spreads by attaching itself to files or programs.
5. Spyware: Software that secretly collects information about users.
6. Password Attacks: Attempts to gain unauthorized access to accounts.
7. Denial of Service (DoS): An attack that makes a website or service unavailable.
8. Man-in-the-Middle (MITM): An attack in which someone secretly intercepts communication between two parties.
🎯 Effects of Cyber Threats
- Data theft
- Financial loss
- Privacy violations
- System damage
- Business disruption
- Identity theft
💡 How to Prevent Cyber Threats?
- Use strong passwords.
- Enable two-factor authentication (2FA).
- Avoid clicking suspicious links.
- Keep software updated.
- Use trusted antivirus software.
- Never share confidential information with unknown people.
🔒 Conclusion
Cyber threats are a major challenge in today's digital world. Understanding these threats and following proper security practices helps protect our data, devices, and online identity.

# 🖥️ What is Virtualisation?
Virtualisation is a technology that allows us to create multiple virtual computers (virtual machines) on a single physical computer using software.

It helps users run different operating systems, applications, and environments on the same physical machine without needing separate computers.
## 1. Example of Virtualisation
Suppose you have one Windows computer. Using virtualisation software like VirtualBox or VMware, you can install and run:
- Windows 11 (Main computer)
- Kali Linux (Virtual machine)
- Ubuntu Linux (Virtual machine)
All these operating systems can run on the same physical computer.

## 2. Why Do We Use Virtualisation?
1. Cost Saving: Reduces the need to purchase multiple physical computers.
2. Resource Sharing: Allows multiple virtual machines to share hardware resources.
3. Security: Provides isolated environments for testing and learning.
4. Flexibility: Allows users to run different operating systems on one computer.
5. Easy Backup: Virtual machines can be copied, backed up, and restored.

1. Host Machine

The physical computer on which virtualisation software is installed and virtual machines are created.

Example: Your actual Windows laptop or desktop.

2. Guest Machine

A virtual computer that runs inside the host machine using virtualisation software.

Example: Kali Linux or Ubuntu running inside VirtualBox.

# What is Hypervisor?

A Hypervisor is software or firmware that creates, runs, and manages Virtual Machines (VMs) on a physical computer. It allows multiple operating systems to run on a single physical machine.

A hypervisor manages hardware resources such as CPU, RAM, storage, and networking and allocates them to different virtual machines.
## 1. Types of Hypervisor
There are 2 main types of Hypervisors.
### Type 1: Bare-Metal Hypervisor
- Runs directly on the physical hardware.
- Does not require a traditional host operating system.
- Provides high performance and efficiency.
- Mostly used in servers and data centres.
